# 雷电 · 复古突击 (Retro Raiden)

纯单文件 H5 竖版射击游戏，无任何外部依赖（断网可玩），双击 `index.html` 即可运行。

## 操作

| 平台 | 移动 | 道具 |
| --- | --- | --- |
| 桌面 | 鼠标移动控制战机（自动开火），也可用 方向键/WASD | 点击屏幕下方按钮，或按 `1`护盾 `2`炸弹 `3`激光 `4`追踪弹 |
| 手机/平板 | 手指任意位置拖动（相对拖拽，不遮挡飞机） | 点按屏幕下方道具按钮 |

`P` 暂停 · `M` 静音

## 玩法要点

- **血量**：玩家 5 颗红心，被弹幕/撞击/激光命中扣 1，受击后短暂无敌并清除近身弹幕。
- **救援**：地面有幸存者挥旗求救，飞到其上空悬停，圆环进度转满即救援成功（+500 分，每救 8 人奖励 1 颗红心）。
- **道具**：击破敌机掉落 `P`火力 `S`护盾 `B`炸弹 `L`激光 `M`追踪弹 `H`红心，拾取后入库，手动释放。
  - 护盾：8 秒泡泡，可挡 3 次伤害
  - 炸弹：全屏核爆，清弹幕 + 大量伤害
  - 激光：5 秒贯穿光束，高 DPS
  - 追踪弹：12 秒自动锁定敌机的小型导弹群
- **敌人**：小飞机（编队）、直升机、碉堡、坦克（炮口追踪）、雷达（五向弹）、导弹车（追踪导弹，可击落）、激光炮塔（预警线→粗光束）。
- **BOSS**：每关关底巨型战舰，**200 颗红心**的超长血条，三阶段攻击（散射→扫射激光+召唤→导弹弹幕），击破后进入下一关，难度递增。
