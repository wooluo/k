# 🎮 BRICKFALL · 破碎星域

一款完整的现代化 HTML5 打砖块街机游戏。纯原生技术栈（HTML5 + CSS3 + Canvas 2D + ES6），**零依赖、零构建**，双击 `game.html` 即可在浏览器中游玩。

## 🚀 运行方式

直接用浏览器打开 `game.html` 即可；或本地起一个静态服务：

```bash
cd 打砖块
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 🕹 操作

| 操作 | 方式 |
|---|---|
| 移动挡板 | 鼠标 / 触摸拖动 / `← →` 或 `A D` |
| 发射球 / 发射激光 | 点击 / `空格` |
| 引爆炸弹 | `B` / 右键 / HUD 炸弹按钮 |
| 暂停 | `P` / `Esc` / HUD 暂停按钮 |

## ✨ 已实现系统

- **物理**：最近点圆矩碰撞、法线反射、子步防穿透（≤6px/子步）、挡板位置角度反弹（±60°）、最小垂直分量防水平死循环、固定时间步 + deltaTime
- **砖块（11 种）**：普通 / 强化 / 重型 / 爆炸（连锁）/ 冰冻 / 金属（仅激光·炸弹·穿透可破）/ 护盾 / 移动 / 传送门 / 不可破坏 / Boss
- **道具（16 种）**：多球、巨型·小型挡板、减速·加速、激光、炸弹、护盾、穿透、烈焰、磁力、粘性、微球、双倍积分、即时奖励、额外生命
- **Combo / Frenzy**：连击倍率（最高 ×10）、5 秒衰减、×10 触发狂暴（积分 ×3 + 球速 +30%）
- **Boss ×2**：机械巨墙（三阶段：移动 / 生成砖块 / 弹幕）、霓虹核心（旋转护盾 + 扇形弹幕）、死亡慢动作演出
- **模式（6 种）**：故事（20 关 + 2 Boss，每关 52~84 块可破坏砖块，7 章框架已预留）、无尽（初始 5 行、持续下压）、限时挑战、挑战（5 个变体规则）、BOSS 连战、经典
- **机关与随机事件**：旋转杆、移动墙、黑洞引力、传送门；陨石风暴、引力异常、黑暗降临、双倍积分、能量加速
- **成长与收集**：三星评价、9 项成就、各模式最佳成绩、localStorage 存档
- **表现**：粒子对象池、球体拖尾、屏幕震动、浮动得分、霓虹星空背景、WebAudio 全合成音效 + 循环 BGM（狂暴加速）
- **适配**：Pointer Events 触控支持、逻辑坐标与渲染分离、响应式缩放（手机 → 桌面）

## 📁 结构

```
game.html          入口与全部界面层
css/style.css       霓虹街机风格样式
js/config.js        常量 / 砖块 / 道具 / 成就 / 世界定义
js/utils.js         数学与碰撞工具（最近点算法、反射、速度修正）
js/audio.js         WebAudio 合成音效 + 16 步音乐序列器
js/particles.js     粒子对象池 / 屏幕震动 / 浮动文字
js/save.js          localStorage 存档管理
js/levels.js        22 个故事关卡 + 经典/限时/挑战数据
js/input.js         Pointer Events + 键盘输入
js/entities.js      球 / 道具掉落 / Boss1 / Boss2 / 旋转杆碰撞
js/game.js          状态机 / 物理 / 渲染主循环（核心）
js/ui.js            屏幕切换 / HUD / 结算
js/main.js          引导入口
test/smoke.js       无头冒烟测试（node test/smoke.js）
```
